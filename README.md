# Лабораторная работа №5 по ООП (2 семестр)

## Описание проекта
Проект демонстрирует основы объектно-ориентированного программирования на C#. Включает 5 классов, каждый из которых показывает различные концепции ООП.

## Классы
1. **Product** - класс товара с названием, ценой и наличием на складе
2. **FuelTank** - класс топливного бака с приватным полем и методами управления
3. **Elevator** - класс лифта с перемещением между этажами
4. **LotteryBall** - класс лототрона для генерации случайных чисел
5. **Employee** - класс сотрудника с уровнем навыка и энергией
